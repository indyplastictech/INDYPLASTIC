# AI OS ของธุรกิจคุณ — ชุดเริ่มต้น (กองทัพ AI · ตัวที่ 1)

คิดเหมือนออฟฟิศจริง: ธุรกิจของคุณ = ออฟฟิศ 1 หลัง มีป้ายหน้าประตูที่ AI อ่านก่อนทำงานทุกครั้ง
ข้างในแบ่งห้องตามงาน ในทุกห้องมี 4 อย่าง — ตั้งครั้งเดียว AI ไม่ต้องให้เล่าใหม่ทุกแชต

## โครงในชุดนี้ (ออฟฟิศ = โฟลเดอร์ใหญ่ · ห้อง = โฟลเดอร์ย่อย)

```
ai-os-starter/          ← เปลี่ยนชื่อเป็นชื่อธุรกิจคุณ (ภาษาอังกฤษ ไม่มีเว้นวรรค)
├─ AGENTS.md            ป้ายหน้าออฟฟิศ: ธุรกิจนี้คือใคร · กติการวม · มีห้องอะไรบ้าง — AI อ่านก่อนทุกครั้ง
├─ CLAUDE.md            1 บรรทัด ชี้ไป AGENTS.md (Claude Code อ่านชื่อนี้)
├─ sales-care/          ห้องแรก · ขายและดูแลลูกค้า — ตั้งคืนนี้
│  ├─ AGENTS.md         กติกาห้อง: AI รับอะไร ห้ามอะไร ส่งต่อคนเมื่อไร
│  ├─ knowledge/        ข้อมูลที่ต้องรู้: prices.md · schedule.md · customers.md
│  ├─ skills/           วิธีทำงานที่สั่งซ้ำได้: reply-booking.md · win-back-90-days.md · draft-post.md
│  └─ memory/           สมุดบันทึก: AI จดเองหลังทำงาน
├─ marketing/           ห้องการตลาดและคอนเทนต์ — วางไว้ก่อน (ตัวที่ 4–5)
├─ backoffice/          ห้องหลังบ้านและบัญชี — วางไว้ก่อน (ตัวที่ 6)
├─ team/                ห้องทีมและ HR — วางไว้ก่อน (ตัวที่ 7)
└─ workflows/           นาฬิกางานอัตโนมัติของทั้งออฟฟิศ — สุดสัปดาห์ 1 ในรุ่น
```

## คืนนี้ทำ 3 ขั้น (30 นาที)

1. **วางโครงออฟฟิศ** — แตกโฟลเดอร์นี้ลงเครื่องคุณ (ไม่ใช่ใน iCloud หรือ Google Drive) แล้วเปลี่ยนชื่อโฟลเดอร์เป็นชื่อธุรกิจ
2. **เขียนป้าย แล้วตั้งห้องแรก** — กรอก `AGENTS.md` 3 ช่อง → `sales-care/AGENTS.md` → `sales-care/knowledge/` 3 ไฟล์
3. **เก็บสำเนาที่ GitHub** — เครื่องอื่นหรือมือถือชี้ที่เดียวกัน

เปิด Claude Code / Codex / Grok / OpenClaw / Hermes ในโฟลเดอร์นี้ แล้วสั่ง: "อ่าน AGENTS.md แล้วตอบลูกค้าที่ถามราคาคอร์ส"
